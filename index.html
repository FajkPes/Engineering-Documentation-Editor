Help - Engineering Documentation Editor (v7.15)

1. Photograph the part

For the best documentation, photograph the front, side, and top views. One photo can be enough when a matching template or an existing .SPOJ project already supplies the other views. Verify details such as hole depth, head type, and diameters before reusing them.

Place a real ruler beside the part when possible. It makes calibration and the 📏 Measure tool much easier to use accurately.

2. Import and prepare images

The left panel imports .SPOJ projects and .ZIP archives containing a .SPOJ file. A .SPOJ project stores the editable document, images, and settings. Use the template overlay for comparison, adjust all images with global pan and zoom, then fine-tune each image slot with crop, rotation, scale, color, and sharpness controls.

3. Configure the document

The right panel controls layout, colors, ruler, typography, and other visual settings. A reusable layout or complete .SPOJ project can save most of this setup work.

4. Crop and align images

Use the crop sliders after loading an image. Hold Ctrl for finer slider movement. Hold Shift while cropping to adjust both opposite edges symmetrically. Keep the views aligned and make sure they do not overlap the properties panel.

5. Calibrate the ruler

Enable Interactive Mode in the toolbar. The optional 👁 Zones overlay highlights interactive areas.

  • Drag the lower part of the ruler to align its zero point with the bottom of the part or the physical ruler in the photo.
  • Drag the mm label to adjust pixels per millimeter. Use the mouse wheel over it to change the ruler range.

6. Measure

Enable 📏 Measure, then click two points. The calibrated distance is converted to millimeters and copied to the clipboard. Account for perspective distortion in the original photo. While the calculator is open, hold Space to measure temporarily.

7. Use the Wizard

Open ✏️ Wizard and work through each property. You may skip ruler calibration and return to the wizard later. The final step opens the calculator for the screw or nut dimensions.

8. Calculate mass and dimensions

Open 🧮 Calculator and select the screw/mass tab. Enter the diameter, length, head, hole, thread, and material density that apply to the part. Validation catches conflicting dimensions and calculates length T when enough values are available. Use 📋 Fill Properties to write the results into the calculator-managed property folder.

9. Save and export

Export a complete 📦 ZIP, a presentation-ready JPG, or an editable .SPOJ project. A .SPOJ file—or a ZIP containing one—can be imported again later.

Other useful features

  • Presets store complete configurations and can be moved between installations as .batch.spoj.
  • ⚙ Advanced contains keyboard shortcuts, grid and snapping tools, history behavior, appearance options, and diagnostics.
  • Export / Import Layout transfers selected appearance and positioning settings without replacing product values.
  • Undo / Redo is available from the panels and preview toolbar.
  • Parser attempts to populate the calculator from a .pxz archive or JSON manifest. Treat its result as a draft and verify every value.
