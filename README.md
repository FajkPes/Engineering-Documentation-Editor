# Engineering Documentation Editor

An offline editor for creating and maintaining engineering product documentation.

## Key features

- Edit product cards, dimensions and images.
- Calculate mass and reuse presets.
- Save editable SPOJ projects locally.

## Get started

Download the ZIP from Releases and follow the included instructions.
