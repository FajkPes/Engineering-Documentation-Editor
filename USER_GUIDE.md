# User Guide

## Starting a new document

Open `index.html` or use the included launcher. The application starts with an English example document so every editable area is visible immediately. Replace the example values and images with your own.

For a guided setup, click **Wizard**. The wizard walks through regular properties, ruler calibration, and the calculator-managed dimensions folder.

## Images and template overlay

Use the image slots in the left panel for front, side, top, or any other useful views. Each slot has independent crop, rotation, scale, color, brightness, contrast, saturation, sharpness, and edge-fade settings. Global image pan and zoom applies an additional offset to every slot.

Use a template image as a visual overlay when you want to align the product with an existing drawing. Adjust template opacity and positioning until the photograph and reference match.

Hold **Ctrl** while moving sliders for finer adjustments. Hold **Shift** while cropping to move both opposite edges symmetrically.

## Ruler and measurement

1. Include a ruler or another known dimension in the photograph.
2. Enable **Interactive Mode**.
3. Move the ruler zero point to the correct reference position.
4. Adjust the ruler zoom in pixels per millimeter and its displayed range.
5. Enable **Measure** and click two points.

The measured value is copied to the clipboard. While the calculator is open, hold **Space** to enter measurement mode temporarily.

## Calculator

The screw/nut calculator supports a cylindrical or hexagonal head, shank and thread dimensions, optional holes and internal threads, and material density. It estimates component volumes and total mass, validates conflicting dimensions, and can fill the calculator-managed properties folder.

Always verify the result against the real part. Perspective distortion, incomplete geometry, coatings, and material differences can affect accuracy.

## Saving and transferring work

- Export **JPG** for a finished documentation image.
- Export **.SPOJ** to preserve an editable project and its images.
- Export **ZIP** for a JPG plus editable project in one package.
- Use **Presets** for frequently reused complete configurations.
- Export presets as **.batch.spoj** to move them to another computer.
- Use **Export / Import Layout** when you want to transfer appearance and positioning without replacing all product values.
